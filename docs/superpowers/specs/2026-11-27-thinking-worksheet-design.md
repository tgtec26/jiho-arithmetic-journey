# 지호의 생각 퍼즐 학습지 (사고력 수학) 설계

작성일: 2026-11-27 · 곱셈(`2026-11-26-multiplication-worksheet-design.md`), 나눗셈(`2026-11-27-division-worksheet-design.md`)에 이어지는 세 번째 세트

## 1. 의도

- 아빠가 "단순 수식 계산 말고 만 6세 아이가 할 만한 사고 수학"을 원한다.
- 지호는 계산(두 자리 곱셈·나눗셈)은 나이보다 앞서 있지만 공간·논리·경우의 수는 또래 수준이라, 계산이 거의 없는 퍼즐이 새 자극이 된다.
- 같은 등장인물(지호·아빠·감돌이·사랑이·손님)의 4컷 만화가 그 회 퍼즐로 이어지고, 같은 종류 퍼즐을 점점 어렵게 풀어 본다.

## 2. 목표 / 비목표 / 반목표

**목표**
- 네 활동: 주차장 탈출, 쌓기나무, 경우의 수, 논리 퍼즐(줄 세우기 + 4×4 스도쿠).
- 모든 퍼즐은 코드가 그리고 코드가 검사한다(풀리는지, 답이 하나뿐인지, 난이도 범위 안인지).
- "빠짐없이" 세는 연습은 칸 구성으로(경우의 수 늘어놓을 칸, 쌓기나무 층별 칸). "어떻게 알았어?"는 아빠가 말로 묻는다 — 쓰는 칸은 없고 정답지 맨 위에 안내 한 줄. (Claude가 정함: 만 6세에게 설명 쓰기는 부담이고 94 × 86mm 칸에 자리도 없음)

**비목표**: 디지털·화면용 버전, 시간 재기·점수, 네 활동 밖의 다른 활동(칠교·저울·님 게임 등).

**반목표**
- 답이 없거나 여러 개인 퍼즐 / 그림이 틀린 퍼즐(쌓기나무 그림과 정답이 안 맞음 등).
- 계산이 슬며시 주인공이 됨(큰 수 곱셈으로 푸는 경우의 수 등).
- 곱셈·나눗셈 세트와 그림체·틀이 달라 보임 / 화자 없는 말풍선.
- 상품 퍼즐을 베낌: 상품명 "러시아워"를 쓰거나 상품 퍼즐 카드를 그대로 옮김. 퍼즐은 모두 우리 생성기가 만든다.
- 오리기 힘들 만큼 작은 차 조각 / 칸 배치로 답이 새어 나감(일부러 주는 힌트는 예외).

## 3. 그대로 이어받는 것

- A4 양면 1장 = 1회: 앞면 위 2/3 4컷 만화 + 아래 ①(이야기 퍼즐, ⭐ 주황 테두리) ②, 뒷면 ③~⑧. 문제 칸 94 × 86mm.
- 만화 규칙: 흰 배경, 말풍선 자동 배치(화자 머리 위, 화자 필수), 14pt 대사, 4번 컷 마지막 말풍선은 질문. 9번 선수는 하늘색 유니폼(`guest-soccer9-sky`).
- 컬러 프린터지만 배경 색은 적게.
- 빌드(크롬 PDF, 페이지 수 검사, `--strict`), 회차별·묶음·정답지 PDF, 어드민(만화 텍스트 편집·미리보기·PDF 다시 만들기).
- 개인정보: 실제 아이 사진은 외부 생성 서비스에 보내지 않음. 인형 참고 사진은 로컬에만(gitignore). 실제 선수는 닮게 그리지 않음.

## 4. 사용자가 정한 것

- 활동: **주차장 탈출, 쌓기나무, 경우의 수, 논리 퍼즐** 네 가지 모두.
- 구성: **한 회에 한 활동, 돌아가며.** 만화가 그 회 퍼즐로 이어지고, 뒷면은 같은 활동을 점점 어렵게.
- 제안(5~8절) 전체 승인: 24회, 오려 쓰는 차 조각 따로 1장, 경우의 수 칸 힌트, 스도쿠는 ●▲■★ 모양 등.

## 5. 회차 구성

- 24회. 회차 번호로 활동이 정해진다: 1·5·9·13·17·21회 주차장 탈출, 2·6·…·22회 쌓기나무, 3·7·…·23회 경우의 수, 4·8·…·24회 논리 퍼즐.
- 활동마다 6번 나오며, 그 활동의 몇 번째인지(라운드 1~6)로 난이도·힌트를 정한다.
- 한 장 안에서도 ①→⑧로 어려워진다. 단 ①은 만화 이야기 퍼즐이라 ②보다 쉽거나 같게 둔다.

## 6. 활동별 문제 칸

### 6.1 주차장 탈출

- 6×6 주차장. 오른쪽 벽 세 번째 줄에 출구. 빨간 차(가로 2칸)는 출구 줄에 있다.
- 다른 차: 2칸 차, 3칸 트럭. 가로 차는 좌우로, 세로 차는 위아래로만 민다. 돌리거나 들어 옮기지 않는다.
- 한 번 움직임 = 차 하나를 한 방향으로 미는 것(몇 칸이든 한 번).
- 판에는 칸 격자와 차 자리 테두리만 그린다. 빨간 차 자리는 빨간 테두리. 각 테두리에 작은 글자(A, B, …)를 적어 정답지와 맞춘다.
- 아이는 따로 인쇄해 오려 둔 조각을 테두리에 맞춰 올려놓고 밀어 본다. 조각은 종류(빨간 차/2칸 차/3칸 트럭)만 맞으면 어느 테두리에 놓아도 된다.
- 칸 아래: `몇 번 움직였니? ___번  (가장 적게: ○번)`. 가장 적은 횟수를 보여 줘서 도전 목표로 삼는다.
- 퍼즐은 문자열 6줄로 적는다(`.` 빈칸, `R` 빨간 차, 다른 글자 = 차 하나). 빌드 때 너비 우선 탐색으로 풀어 가장 적은 횟수가 적힌 값과 같은지 검사한다.
- 가장 적은 횟수(라운드별 범위): 1: 1~3, 2: 2~4, 3: 3~6, 4: 4~7, 5: 5~9, 6: 6~11.
- 힌트: 라운드 1·2의 ①은 첫 움직임을 회색 화살표로 보여 준다.

**차 조각 장** (따로 1장, 한 번만 인쇄)
- A4 한 면, 양면 묶음에 넣지 않고 따로 PDF. 빨간 차, 2칸 차, 3칸 트럭을 24회 중 가장 많이 쓰는 개수보다 2개씩 넉넉히.
- 조각 크기 = 판 칸 크기와 정확히 같음(칸은 10mm 이상). 위에서 본 차 모양을 코드로 그림. 자르는 선 표시, 두꺼운 종이 권장 문구.

### 6.2 쌓기나무

- 바닥 칸마다 블록을 쌓은 탑(공중에 뜬 블록 없음). 높이 지도로 적는다(예: 뒤→앞 줄, 왼→오른 칸의 높이 `["210","110"]`).
- 입체 그림은 코드가 등각(아이소메트릭) 그림으로 그린다. 면 세 개는 한 색의 세 밝기. 그림 옆에 `앞`, `옆`(오른쪽) 화살표.
- 모든 탑의 윗면이 그림에서 보여야 한다(숨은 탑 없음) → "뜬 블록 없음" 규칙과 함께 개수가 하나로 정해진다. 빌드가 검사.
- 묻는 것(칸마다 1~2개): 블록 개수 / 위에서 본 모양 / 앞에서 본 모양 / 옆에서 본 모양 → 빈 모눈에 색칠. 라운드 5·6은 위에서 본 모양 모눈에 칸마다 층수 쓰기도.
- 라운드별: 블록 수 1: 3~5, 2: 4~6, 3: 5~8, 4: 6~9, 5: 7~10, 6: 8~12. 바닥 2×2 → 3×3, 높이 3층까지. 묻는 방향은 라운드 1 위, 2부터 앞, 3부터 옆을 더함.
- 힌트: 라운드 1·2의 개수 문제에 `1층 ___개, 2층 ___개, 3층 ___개` 칸(숨은 아래 블록 세기 연습).

### 6.3 경우의 수

- 문제 틀(템플릿) 네 가지, 답은 코드가 직접 늘어놓아 센다:
  - **짝 짓기**: 윗옷 m × 아랫도리 n(유니폼 셔츠·바지, 콘·아이스크림 맛). 양쪽에 그림, 선을 그어 짝 짓기.
  - **순서 정하기**: 기차 칸 3개 순서, 3명 줄 서기, 4명 중 1등·2등.
  - **고르기**: 맛 4개 중 2개, 4팀(5팀) 축구 리그 경기 수, 악수.
  - **가장 짧은 길**: a × b 격자에서 집 → 학원. 작은 격자 여러 개에 길을 하나씩 그림.
- 답 크기는 12가지 이하(계산 말고 늘어놓기가 목적).
- 항목은 색·모양으로 구별되는 단순한 그림(코드 또는 스티커). 아이가 쓰기 쉽게 이름 첫 글자나 색으로 적게 한다.
- 칸 아래: `모두 ___가지`.
- 힌트(늘어놓을 칸): 라운드 1·2 = 답과 같은 수의 빈칸(빠짐없이 채우기 연습), 3·4 = 답보다 2~4개 많은 빈칸("남는 칸이 있어도 돼요"), 5·6 = 빈칸 없이 빈 공간에 스스로.
- 라운드별로 틀과 크기를 늘림: 1·2는 짝 짓기·순서(답 6 이하), 3·4는 고르기·짧은 길 추가(답 10 이하), 5·6은 섞어서(답 12 이하).

### 6.4 논리 퍼즐

한 회에 두 종류를 4문제씩 섞는다: ① 줄 세우기(만화 이야기), ② 스도쿠(가장 쉬운 것), 뒷면 ③~⑤ 줄 세우기, ⑥~⑧ 스도쿠. 종류마다 쉬운 것부터. (Claude가 정함: 앞면에서 두 종류를 다 맛보게)

- **줄 세우기**: 등장인물(또는 기차·자동차) 3~5개를 단서로 순서 정하기.
  - 단서: 맨 앞/맨 뒤, 바로 앞/바로 뒤, ~보다 앞/뒤, 가운데, (라운드 4부터) ~와 붙어 있지 않음.
  - 줄 방향을 그림으로(왼쪽 = 앞, 예: 매표소). 빈칸 줄에 이름(첫 글자)을 쓴다.
  - 모든 순서를 늘어놓아 단서를 만족하는 순서가 정확히 하나인지 빌드가 검사.
  - 라운드별: 1: 3개·단서 2, 2: 3개·단서 2~3, 3: 4개·단서 3, 4: 4개·단서 3~4, 5: 4~5개·단서 4, 6: 5개·단서 4~5.
  - 힌트: 라운드 1·2는 한 자리를 회색으로 미리 채워 줌.
- **4×4 스도쿠**: ●▲■★, 가로줄·세로줄·2×2 칸마다 모양이 하나씩.
  - 빈칸 수 라운드별: 1: 4~5, 2: 5~6, 3: 6~7, 4: 7~8, 5: 8~9, 6: 9~10.
  - 답이 하나뿐인지 빌드가 검사.

## 7. 만화

- 24개 새 이야기. 4컷: ①상황 ②퍼즐이 생긴 까닭 ③규칙 설명 ④질문.
- 예: 아빠 차가 주차장에서 막힘, 감돌이가 블록 탑을 쌓음, 지호가 축구 유니폼을 고름, 사랑이·감돌이가 기차 표를 사려고 줄 섬.
- 소재: 축구·기차·자동차·레고 코딩·피아노·영어·사랑이·감돌이.
- 필요한 소품 스티커는 같은 그림체로 Codex로 추가(곱셈·나눗셈 세트와 같은 방식).

## 8. 정답지

- 맨 위 안내 한 줄: "답을 맞히면 '어떻게 알았어?' 하고 물어봐 주세요."
- 회차마다: 주차장 = 가장 적은 횟수 + 움직이는 순서(`B ↑1, C ←2, R →4` 꼴), 쌓기나무 = 개수 + 작은 모양 그림, 경우의 수 = 가지 수(+ 짧게 늘어놓은 목록), 논리 = 순서 / 채운 스도쿠 작은 그림.

## 9. 만드는 방법 (Approaches)

- **A. 지금 학습지 시스템에 세 번째 세트를 더함 (선택).** 만화·페이지·빌드·어드민·정답지를 그대로 쓰고, 활동마다 그리는 코드와 검사 코드만 새로 만든다. 곱셈·나눗셈 때 만든 세트 구조(`lib/sets.js`)에 그대로 들어간다.
- B. 따로 새 프로그램: 만화·빌드를 다시 만들어야 해서 뺌.
- C. AI로 퍼즐 그림 생성: 그림이 정답과 어긋나도 잡을 수 없어서 뺌.

사용자는 결과물 이야기를 했고 만드는 방법은 빌더(Claude)에게 맡겼다. 한 가지 방법만 맞아서 A로 정했다.

## 10. 결과물과 구조

- 데이터: `worksheets/data/think/epNN.json` — 공통 머리(id, 제목, 아이콘, 만화) + 활동별 퍼즐 8개(문제 데이터 그대로 적음).
- 코드: 활동마다 숫자·검사 모듈과 그리는 모듈. 곱셈·나눗셈 모듈은 건드리지 않는다.
- 빌드: `--set=think`. 출력 `worksheets/out/pdf/think/` 에 회차별·묶음·정답지 PDF + 차 조각 PDF.
- 머리줄 색만 달리해 세트 구별(초록 계열 제안).
- 어드민: 위쪽 세트 탭에 "생각 퍼즐" 추가, 만화 텍스트 편집. 퍼즐 데이터는 JSON에서 고친다.

## 11. 빌더에게 맡기는 것

- 칸·조각의 정확한 mm, 색, 그림 세부(등각 그림 각도, 차 모양), 안내 문구.
- 24회 이야기 대사, 퍼즐 생성 방법, 소품 목록.
- 머리줄 색, 세트 이름 표기.
