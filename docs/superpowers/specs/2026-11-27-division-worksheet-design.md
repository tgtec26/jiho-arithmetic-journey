# 지호의 나눗셈 이야기 학습지 (두 자리 수 ÷ 한 자리 수) 설계

작성일: 2026-11-27 · 곱셈 학습지(`2026-11-26-multiplication-worksheet-design.md`)에 이어지는 두 번째 세트

## 1. 의도

- 곱셈 학습지를 마친 지호가 같은 등장인물·소재로 나눗셈을 시작한다. 아빠와 4컷 만화를 읽고 이야기 속 나눗셈 1문제 + 같은 수로 나누는 변형 7문제.
- 지호 수준: 곱셈 초심자, 7·8·9단은 아직 헷갈림. 나눗셈은 처음.

## 2. 목표 / 비목표 / 반목표

**목표**
- 두 자리 수 ÷ 한 자리 수, 몫은 두 자리.
- 곱셈의 "격자 + 세로셈"처럼 **쪼개서 나누기 + 세로식(긴 나눗셈)** 을 나란히 두어 교과서 세로식으로 넘어가는 다리를 놓는다.
- 앞 회차는 딱 나누어떨어지는 문제만, 뒤 회차부터 나머지.
- 곱셈으로 확인하는 습관(몫 × 나누는 수 + 나머지 = 나누어지는 수).

**비목표**: 세 자리 수 나눗셈, 두 자리 수로 나누기, 디지털 채점.

**반목표**: 곱셈 세트와 그림체·틀이 달라 보임 / 7·8·9단이 앞 회차에 나옴 / 칸이 좁음 / 화자가 없는 말풍선.

## 3. 그대로 이어받는 것 (곱셈 세트와 동일)

- A4 양면 1장 = 1회: 앞면 위 2/3 4컷 만화 + 아래 ①(이야기) ②, 뒷면 ③~⑧. 문제 칸 94 × 86mm.
- 등장인물(지호·아빠·감돌이·사랑이·손님), 스티커, 흰 배경, 말풍선 자동 배치(화자 머리 위, 화자 필수), 14pt 대사, 4번 컷 마지막 말풍선은 질문.
- 빌드(크롬 PDF, 페이지 수 검사, `--strict`), 정답지, 어드민(텍스트 편집·미리보기·PDF 다시 만들기).
- 9번 선수는 하늘색 유니폼(`guest-soccer9-sky`).

## 4. 사용자가 정한 것

- 수준: **두 자리 ÷ 한 자리**.
- 계산 틀: **C. 쪼개기 + 세로식 나란히**.
- 나머지: **뒤 회차부터**.

## 5. 문제 칸 (C안)

- 맨 위: `① 48 ÷ 3` (이야기 문제는 ⭐, 주황 테두리).
- 왼쪽 "쪼개기":
  - `48 = [30] + [18]` — 나누는 수로 나누기 쉬운 두 수로 쪼갬. 첫 수 = 나누는 수 × 10 × (십의 자리를 나누는 수로 나눈 몫), 둘째 수 = 나머지 부분. (48÷3 → 30+18, 72÷4 → 40+32, 96÷8 → 80+16, 50÷3 → 30+20)
  - `● 30 ÷ 3 = [  ]` (주황), `● 18 ÷ 3 = [  ]` (파랑) — 나머지가 있는 문제는 둘째 줄이 `20 ÷ 3 = [ ] … [ ]`.
  - `몫 = ● + ● = [  ]`
- 오른쪽 세로식(긴 나눗셈), 한 칸에 숫자 하나:
  - 몫 줄(2칸) / `3 ) 4 8` / 십의 자리 곱(주황 점) / 빼고 내려쓴 수 / 일의 자리 곱(파랑 점) / 나머지. 곱셈 세로셈처럼 줄 사이 빈 간격, 받아올림 칸 같은 작은 칸 없음.
  - 왼쪽 주황·파랑 줄과 세로식의 같은 색 점 줄이 짝 (주황 = 십의 자리 단계, 파랑 = 일의 자리 단계).
- 맨 아래 확인: `확인: [몫] × 3 (+ [나머지]) = 48`.
- 이야기 문제는 `답: ____ 개` (나머지 있는 회차는 `답: ____ 개, 남는 것 ____ 개`).

## 6. 숫자와 난이도 (내 제안)

- 회차마다 **나누는 수 고정**(곱셈의 "16 고정"과 같은 생각). 이야기 = `나누어지는 수 ÷ 고정 수`, ②~⑧ = `다른 수 ÷ 고정 수`.
- 몫은 항상 두 자리(나누어지는 수의 십의 자리 ≥ 나누는 수).
- 7·8·9단 조절은 **나누는 수 자체**로 한다. 몫이 두 자리면 쪼개기에서 나오는 곱(나누는 수 × 몫의 각 자리)은 6×6을 넘지 않아 곱셈 세트의 "어려운 곱" 기준은 쓰지 않는다. (빌더 검토 반영)
- 내림: 십의 자리가 나누는 수로 딱 나누어지지 않아 남는 수를 일의 자리로 내려야 하는 경우(예: 52÷4 → 40 + 12).
- 몫의 일의 자리가 0인 문제(60÷3 = 20, 62÷3 = 20 … 2): 1~14회에는 넣지 않고 15회부터 섞는다. 세로식은 모양을 바꾸지 않고 일의 자리 단계에 `3 × 0 = 0` 줄을 그대로 쓴다.
- 한 회의 8문제는 서로 다른 나누어지는 수. 몫 두 자리 + 나머지 없음 조건에서 쓸 수 있는 수가 나누는 수 6은 7개, 8은 3개, 9는 2개뿐이라 단계별 나누는 수를 아래처럼 정한다. (빌더 검토 반영)
- 단계:
  - 1~6회: 나누는 수 2·3·4, 나머지 없음. 내림은 문제당 1곳 이하이고 내림 있는 문제는 뒤쪽 ⑦⑧에만.
  - 7~14회: 나누는 수 2~5, 나머지 없음, 내림 있는 문제 자유.
  - 15~24회: 나누는 수 3~9, 나머지 있는 문제와 몫의 일의 자리 0인 문제를 섞음(이야기 문제도 나머지 가능). 8·9는 몫이 10~12로 좁아서 각각 한 회씩만.
- 난이도 정렬(쉬운 것 → 어려운 것): 내림 없음 → 내림 있음 → 나머지 있음, 같으면 나누어지는 수 작은 순.

## 7. 힌트 줄이기 (곱셈과 같은 4단계)

- 1~6회: 쪼갠 수를 회색으로 보여 줌(`30 + 18`), 세로식에 단계 회색 안내.
- 7~14회: 쪼개는 첫 수만 회색(`30 + □`).
- 15~20회: 쪼개기 칸 비움.
- 21~24회: 쪼개기 작게, 세로식 중심.

## 8. 이야기

- 같은 소재(축구·기차·자동차·레고 코딩·피아노·영어·사랑이·감돌이)로 새 이야기 24개. 4컷: ①상황 ②나눌 전체 ③나누는 수(사람·묶음) ④질문.
- 1~14회는 "똑같이 나누면 하나에 몇 개?"(등분), 15회부터 "몇 묶음/몇 명?"(포함)과 "남는 것은?"도 섞음.
- 필요한 소품 스티커는 Codex로 같은 그림체로 추가.

## 9. 결과물과 구조

- 데이터: `worksheets/data/division/epNN.json` (곱셈은 `data/episodes/` 그대로).
- 코드: 곱셈 모듈은 그대로 두고 나눗셈 전용 `lib/division.js`(숫자 규칙), `lib/render-division.js`(문제 칸)를 추가. 만화·페이지·빌드·어드민은 세트(곱셈/나눗셈)를 고를 수 있게 넓힌다.
- 출력: `worksheets/out/pdf/division/` 에 회차별·묶음·정답지 PDF. 머리줄 제목 색만 달리해 두 세트를 구별(나눗셈은 파랑 계열).
- 어드민: 위쪽에서 곱셈/나눗셈 세트를 고르는 탭.

## 10. 빌더에게 맡기는 것

- 세로식 칸의 정확한 mm, 단계 안내 문구.
- 24회 이야기 대사와 숫자(6·8절 규칙 안에서), 소품 목록.
- 머리줄 색.
